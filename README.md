# ПР 3_5. Модулі. Класи

Практична робота з дисципліни «Розробка web-застосувань».
Тема: Об'єкти та прототипи. Класи в JavaScript. Модульна структура ES6.

## Виконане завдання:
1. Проведено повний рефакторинг коду.
2. Створено універсальний клас `Pokemon` (файл `pokemon.js`), який створює як героя (`character`), так і супротивника (`enemy`).
3. Код логічно розділено на окремі ES6-модулі:
   - `pokemon.js` — опис класу `Pokemon` з методами зміни HP та візуалізації прогрес-бару;
   - `utils.js` — утиліти генерації випадкових чисел `random` та функція замикання лічильника кліків `countBtn`;
   - `logs.js` — модуль генерації бойових повідомлень `generateLog`;
   - `main.js` — точка входу гри, що імпортує модулі та вішає обробники подій.
4. В `index.html` підключено головний скрипт з атрибутом `type="module"`.
